**So wird es geschrieben**

- Jede Spalte beginnt mit einer Marker-Zeile
- Der erste Marker öffnet die Region
- Die Überschrift darüber bleibt volle Breite

**Was dabei herauskommt**

- Gleich breite Spalten ohne eigenes CSS
- Breiten über `columns: 2:1` steuerbar
- `end-columns` gibt die volle Breite zurück
